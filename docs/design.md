# 个人主页设计说明

2026-08-03

## 目的

一个「人生主页」，而不是简历页。它同时承载两件事：专业面（空间音频研究、专利、AI 智能体）
和生活面（书单、影单、歌单、活动记录）。深度内容都已经在 LinkedIn 和小红书上，
这个站的职责是**聚合与呈现**，不是再造一套写作系统。

## 形态

首页精选 + 三个归档页。

首页每个板块只放最近 3–5 条，保证版面克制、一屏一个节奏；
书 / 影 / 乐各有一个归档页放全量，这样内容长大时首页不会失控。

放弃的选项：单页长滚动（书影音一多就没完）、自建博客（重复投入，大概率荒废）。

## 信息架构

首页五段，每段是一个编辑单元：

| 板块 | 内容 | 去向 |
|---|---|---|
| Masthead | 姓名，大字 | — |
| Hero | 人像 + 一句话定位 + 自述 + 社交入口 | LinkedIn / 小红书 / IG / Email |
| 01 工作与研究 | 年份 + 标题 + 一句话 | LinkedIn / 论文 / 专利 |
| 02 近况 | 图 + 日期 + 标题 + 短句 | 小红书 / Instagram |
| 03 在读·在看·在听 | 每类 4 张封面 | 归档页 |

归档页 `/reading`、`/watching`、`/listening` 共用一套模板。

## 双语

中文在根路径，英文在 `/en/`。两种语言共用同一份数据——
`site.json` 里每个文案字段都是 `{ zh, en }` 两个子字段，页面按当前语言取值。
因此新增内容只写一处数据，不用维护两套页面。

排版按语种切换：
- 中文标题走 Noto Serif SC，正文行高 1.95（中文需要更松的行距）
- 英文标题走 Libre Bodoni，正文 Public Sans，行高 1.75
- **中文一律不用意大利体**——宋体没有真正的斜体，浏览器会强行倾斜，很难看

## 视觉

Vogue 的骨架 + Popeye 的血肉。

上半页靠 Didone 衬线的尺度落差和 1px 黑线建立权威感（研究成果需要这个），
下半页靠暖纸色和编号小格子建立温度（书影音需要这个）。
两者靠统一的网格、字距和分隔线缝合。

| 角色 | 值 |
|---|---|
| 墨黑 | `#111111` |
| 暖纸（页面底色） | `#F6F1E7` |
| 图片占位 | `#E7E3DA` |
| 细分隔线 | `#D8D2C4` |
| 次要文字 | `#6B675E` |
| 朱橙（点缀） | `#C8501E` |

朱橙只用在小面积：章节编号、外链箭头、语言切换的当前项。一旦大面积使用就会破坏纸感。

站点只做浅色。杂志的纸感是刻意的单一选择，深色版会削弱它。

## 图片

杂志风的成败 80% 在图片。当前全部是占位块——`Frame.astro` 在没有图时渲染一个
排版过的占位框而不是裂图，所以缺图不影响上线。

统一的比例和色调是「所有图看起来像同一本刊物拍的」的来源，比例约定见 README。

## 技术

Astro + Tailwind，静态输出，部署到 Cloudflare Pages。

选 Astro 的理由：默认零 JavaScript（编辑风页面本质是排版和图片，首屏要快）、
内置图片管线（自动出 WebP/AVIF 和 srcset）、内置 i18n 路由、内容即数据。

已知取舍：Cloudflare Pages 在国内访问速度不稳定。先上线观察，
确实成为问题再考虑国内服务器 + 备案——不为它提前增加复杂度。
